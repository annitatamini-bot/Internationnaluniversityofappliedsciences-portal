# IU Applied Sciences — Student Portal

A responsive English-language student portal for **International University of Applied Sciences**.

## Included

- Dashboard with programme progress, current average, timeline and course shortcuts
- Semester 3 and Semester 4 course catalogue
- Seven course spaces with ten structured learning modules each and a 100+ page course-pack presentation
- Official transcript view for **TAMINI Annita Richmonde Habué** with grades and print/download support
- Master Thesis workspace with progress milestones, supervisor and deadline
- Certificate of Achievement preview that clearly remains pending until thesis validation and final academic review
- Responsive layout for desktop and mobile

## Run locally

Open `index.html` in a browser. No build step or backend is required.

## Academic content

The course cards provide the programme structure and ten-module reading plan for each course. The individual full 100-page academic manuscripts, assessments, references and authentication layer should be added as the next content/backend phase rather than represented as fabricated credentials.

## Note

This is a front-end prototype. The transcript and certificate are illustrative UI records and are not official academic documents.
